# 📊 Sales Performance Dashboard (Excel Project)

An interactive Sales Dashboard built using Microsoft Excel to analyze sales performance, profit trends, customer behavior, and regional distribution.

This project demonstrates data cleaning, pivot table analysis, dashboard design, and data visualization skills using Excel.

---

## 📌 Project Overview

The goal of this project is to transform raw sales data into meaningful business insights through an interactive and visually appealing dashboard.

The dashboard enables users to:
- Monitor total sales performance
- Track profit trends over time
- Analyze category-wise sales
- View state-wise sales distribution
- Identify top customers
- Explore monthly trends

---

---

## 📊 Dashboard Features

### 1️⃣ Sales by Category
Displays sales performance for different product categories.

### 2️⃣ Profit Gained Over Time
Shows year-wise profit trends to analyze growth patterns.

### 3️⃣ Sales by State (Map Visualization)
Geographical representation of sales distribution across states.

### 4️⃣ Customer Count Analysis
Tracks customer growth across years.

### 5️⃣ Monthly Sales Trend
Visual representation of month-wise sales performance.

### 6️⃣ Interactive Filters
- Category slicer
- Year slicer

Users can dynamically filter the dashboard for better analysis.
